# X-Ray Bump Tool

Небольшая Windows-программа для пакетной генерации bump-текстур X-Ray Engine.

## Запуск без Python

Дважды щёлкните `XRayBumpTool.exe`, выберите папку с DDS и нажмите
«Сгенерировать». EXE автономный: устанавливать Python, Pillow или NumPy не
нужно.

`XRayBumpTool.cmd` оставлен как вариант для запуска программы из исходников.

Для каждого исходного DDS создаются:

- `_bump.dds` — DXT5, gloss в R и нормаль в GBA;
- `_bump#.dds` — коррекция нормали и height в alpha;
- `_bump.thm`;
- исходный `.thm` с корректной ссылкой на bump.

Карты содержат полный mip-chain. Готовые `_bump` и `_bump#` никогда не
считаются исходниками. По умолчанию существующие пары пропускаются, а в
существующем THM сохраняются все сторонние chunks и меняется только bump-связь.

Профиль материала выбирается автоматически по имени файла. Отражения металла и
сила рельефа регулируются двумя выпадающими списками.
